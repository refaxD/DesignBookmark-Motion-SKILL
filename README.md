# DesignBookmark-Motion-SKILL
Скилл описывает выбор компонента, получение промпта или кода, адаптацию к проекту и проверку анимации

Работает с [каталогом Motion на DesignBookmark](https://designbookmark.com/motion).

## Русская версия

[Читать SKILL.md](ru/designbookmark-motion/SKILL.md).

Папка `ru/designbookmark-motion` содержит скилл и настройки его отображения в Codex. Для переноса скилла скопируйте папку целиком.

## English version

[Read SKILL.md](en/designbookmark-motion/SKILL.md).

The skill covers component selection, copying prompts or source code, integration, and animation checks for [DesignBookmark Motion](https://designbookmark.com/motion).

Copy the entire `en/designbookmark-motion` folder to transfer the skill with its Codex display settings. The two language versions share the same skill name; choose one.
